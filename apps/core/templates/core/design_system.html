Design System

Página de referencia interna (FASE 5, actualizada en la FASE DE REDISEÑO VISUAL SaaS): todos los componentes reutilizables del proyecto, con datos de ejemplo. No es una página de negocio.

Dos identidades, un mismo sistema

El ERP tenant (este shell — sidebar gris claro, marca en --color-primario) conserva azul+verde exactamente como en FASE 5: verde sigue siendo .btn--secundario y aparece en módulos como Ventas/Compras. La plataforma SaaS (Super Admin — Tenants, Planes, Facturación, PayPal, /plataforma/billing/*) usa un shell separado (templates/layout_saas_admin.html) con sidebar azul profundo y nunca usa verde como color estructural — verde queda reservado exclusivamente para éxito. Ningún token existente se eliminó: ambas identidades comparten el mismo base.css/design-system.css.

TokenRolDónde se usa
--color-primario (azul-700)brand / primary / acción / navegaciónTodo el proyecto
--color-saas-sidebar-fondo (azul-950)brand SaaS (solo plataforma).sidebar--saas
--color-secundario (verde-700)acción secundaria (legado ERP)Ventas, Compras — nunca en vistas SaaS nuevas
--color-verde-*success / estado positivobadge--verde, alerta--exito, kpi--exito
--color-advertencia-*warningbadge--advertencia, alerta--advertencia
--color-peligro-*dangerbadge--peligro, alerta--peligro, btn--peligro
--gris-*neutral (superficies, texto secundario)Todo el proyecto
