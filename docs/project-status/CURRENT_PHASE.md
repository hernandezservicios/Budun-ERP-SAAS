## Corrección de Gate Local: Billing SaaS — Alta Inicial + Venta Manual + Activación
Durante el Gate Local de validación manual (posterior al cierre de FASE 20), una transacción PayPal Sandbox real (Order `14B35392VT056762Y`, Capture `04V39124X1030784D`, $29.00 USD, `status=confirmed`) capturada con la herramienta de prueba de plataforma (FASE 16) sobre un tenant creado por venta manual ("Anerol ERP") reveló 3 gaps reales en `apps.billing`, auditados a fondo antes de tocar ningún código (ver `KNOWN_ISSUES.md` #127).

**Causa raíz**: `ManualTenantSaleView` (`apps/billing/admin_views.py`) creaba `Tenant`+`Owner`+`Subscription` pero nunca generaba la primera `SaaSInvoice` (0 filas de `SaaSInvoice`/`SaaSPayment`/`SaaSPaymentAllocation` para el tenant, confirmado por auditoría directa a la base).
