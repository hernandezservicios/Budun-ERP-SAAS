# WACRM — ALINEACIÓN FUTURA

WACRM sigue siendo consumidor externo del ERP.

Para catálogo comercial utiliza:
`/api/v1/catalog/`

Tools genéricas en WACRM:
- `search_catalog`
- `get_product`
- `get_availability`
- `get_product_media`

Budun ERP es provider inicial.

Nunca exponer al agente:
IMEI, serial, costos, margen, proveedor, movimientos internos o datos financieros privados.

Este documento es informativo y no autoriza implementar WACRM.
